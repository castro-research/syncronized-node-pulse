# Introdução

Como manter um pulso sincronizado entre disposivos?

Este projeto é dedicado a entender como funciona um metrônomo sincronizado entre diversos disposivos, considerando redes instáveis, 

O paper que eu comecei a me basear pertence ao Reid Oda, e Rebecca Fiebrink, que escreveram o paper: [The Global Metronome: Absolute Tempo Sync For Networked Musical Performance](https://university.kurz.fyi/pt-BR/papers/global-metronome-absolute-tempo-sync-networked-performance)

Meu objetivo é investigar melhorias do sistema que foi apresentado, em forma de artefatos e uma bateria de testes em volta disso.

A investigação hoje tem uma prova de conceito, que se encontra disponível em https://pulse.kurz.fyi
